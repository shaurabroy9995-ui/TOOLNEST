Frequently Asked Questions

What is ToolNest?

ToolNest is a free, open-source collection of browser-based tools for everyday tasks. All processing happens locally in your browser — your data never leaves your device. We don't collect any personal information or require account creation.

Is ToolNest really free?

Yes, ToolNest is completely free and always will be. We don't charge for any features, subscriptions, or services. You can optionally support us through donations to help keep the project running.

Do I need to create an account?

No account is required. ToolNest works entirely in your browser without any registration or login. Just visit the website and start using the tools immediately.

Is my data safe and private?

Yes. All processing happens locally in your browser. Your files are never uploaded to our servers. We don't store, track, or analyze your data. For complete details, please read our Privacy Policy.

Image Tools

Which image formats are supported?

We support PNG, JPG/JPEG, WebP, BMP, and GIF formats. You can convert between most of these formats and resize images to your desired dimensions.

What's the maximum file size I can upload?

Since processing happens in your browser, the maximum file size depends on your device's memory. Most modern devices can handle files up to 50-100MB without issues.

Will the image quality decrease when I resize it?

When resizing images, quality may decrease if you're enlarging them significantly. For best results, resize images to smaller dimensions. Quality loss is minimal when reducing size and converting formats.

PDF Tools

How many PDFs can I merge at once?

You can merge multiple PDFs together. The number depends on your device's memory and the total file size. Most devices can handle 10-50 files without issues.

Can I reorder pages before merging?

Yes, you can drag and drop PDFs to reorder them before merging. This gives you full control over the final document structure.

Can I split a PDF into individual pages?

Yes, the PDF tool allows you to split a PDF and extract specific pages. Select the pages you want to extract and download them as individual files.

QR Code Generator

What types of data can I encode in a QR code?

You can encode URLs, plain text, contact information (vCard), WiFi credentials, email addresses, phone numbers, and SMS messages. The QR code will encode up to 2953 bytes of data.

Can I customize the QR code appearance?

Yes, you can adjust the error correction level, size, and colors of the QR code. Higher error correction levels allow the code to remain scannable even if partially obscured.

Which formats can I download the QR code in?

You can download QR codes as PNG (raster) or SVG (vector) files. SVG is recommended for scaling to different sizes without quality loss.

Text Tools

What can the Text Cleaner remove?

The Text Cleaner can remove extra spaces, HTML tags, emojis, special characters, and line breaks. You can choose which elements to remove and customize the cleaning process.

Does the Text Cleaner preserve formatting?

The tool removes most formatting by default. However, you can enable options to preserve specific formatting like paragraphs or line breaks.

Base64 Tools

What is Base64 encoding?

Base64 is a way to encode binary data into ASCII text format. It's useful for transmitting data over text-only systems and embedding images in HTML/CSS.

Can I encode files using Base64?

Yes, you can drag and drop files to encode them to Base64. The encoded data can be used in HTML, CSS, or transmitted over text-based protocols.

Troubleshooting

The tool isn't working. What should I do?
  1. Try refreshing the page (Ctrl+R or Cmd+R)
  2. Clear your browser cache and cookies
  3. Try a different browser
  4. Check that JavaScript is enabled in your browser
  5. If the issue persists, contact us
The file is too large to process

This happens when the file exceeds your browser's available memory. Try:

  • Closing other applications to free up memory
  • Using a 64-bit browser instead of 32-bit
  • Splitting the file into smaller parts
  • Trying a different device with more RAM
Downloaded files are empty or corrupted

This is usually a browser issue. Try:

  • Using a different browser
  • Checking your browser's download settings
  • Disabling browser extensions that might interfere
  • Checking available disk space
The tool is slow

Processing performance depends on your device's hardware. Try:

  • Closing other applications
  • Reducing file sizes or batch quantities
  • Using a device with better specifications
  • Ensuring your browser is up to date
