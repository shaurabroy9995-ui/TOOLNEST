📖 How to Use

📸 Resize Images

  1. Select an image file
  2. Enter desired width and height
  3. Click "Resize Image"
  4. Download resized image

🎨 Convert Formats

  1. Select your image
  2. Choose target format
  3. Click "Convert Image"
  4. Download converted file
